01 / TOOL TESTING — IN DEVELOPMENT

See how AI tools perform on the work you need done.

Our comparisons are meant to show which tools fit your work and circumstances, and what you’d be taking on with each.

To get there, several tools receive comparable tasks, each task is run more than once, and we check the outputs independently rather than relying on what the tool reports.

Our first comparisons will focus on AI app builders.

Example test scenario: Building and maintaining a booking app ↓

DECISION

Which AI app builder suits a small-business owner with limited technical experience?

EVALUATION SCOPE

  • Functional reliabilityBooking and cancellation flows, including attempts to reserve the same slot.
  • MaintainabilityIntroducing a new requirement and checking that existing functionality still works.
  • User effortTime, correction attempts and technical assistance needed to complete the task.
  • PortabilityExporting the project and assessing what is required to run it with another provider.

INTENDED OUTCOME

A comparison of which tools suit this user, where specialist help is needed, and the trade-offs involved.

WHAT WE’LL RECORD

Does it work?Whether the output does what the task asked.
FixesWhat errors occur, and how many attempts it takes to resolve them.
TimeFrom the initial instructions to a usable result.
CostWhat it costs to complete the task, including retries.
AssistanceThe guidance and technical knowledge needed to reach a useful result.

WHAT YOU’LL GET

→Options worth trying for your kind of task.
→The circumstances in which each tool struggles.
→The effort and expertise you should expect to contribute.
→The evidence behind the advice, including example outputs.
→The trade-offs that could change the recommendation.
